# Build workspace declarations before typecheck

- **Slug:** `typecheck-build-order`
- **Branch:** `fix/typecheck-build-order`
- **Owner:** Codex
- **Status:** in progress

## Goal

Running the documented recursive typecheck works from a clean checkout, even
when a dependent package imports declarations generated by the engine build.

## Scope

**In:** Run the engine build automatically before its typecheck.

**Out:** User text changes and application behavior.

## Approach

Add the package lifecycle hook `pretypecheck` to `packages/engine/package.json`.

## Claimed paths

- `packages/engine/package.json`

## Acceptance criteria

- [ ] `pnpm -r typecheck` builds engine declarations before checking dependents.
- [ ] Existing user changes remain untouched.
