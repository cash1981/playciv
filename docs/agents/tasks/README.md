# Task briefs

Read only the brief for the active task named in [task-board.md](../task-board.md).
Use [the template](../templates/task-brief.md) for new work. A task brief records
goal, scope and acceptance criteria; it is not permanent product documentation.

Keep a brief while its change is active or under review. After merge, move any
enduring rationale into [decisions](../decisions.md), and concrete unresolved
limitations into [limitations](../limitations.md), then remove the brief in a
subsequent change. Do not delete another live task's brief.

The files headed **Historical reference** are redirects retained for citations
in source/tests/generated data. They are neither active tasks nor pending work.
Do not read their original plans by default. The retired briefs and decision
log can be retrieved using [the history guide](../../history/README.md).
