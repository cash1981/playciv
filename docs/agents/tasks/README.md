# Task briefs

One brief per active task, named in [task-board.md](../task-board.md) and made
from [the template](../templates/task-brief.md). A brief holds goal, scope and
acceptance criteria; it is not product documentation.

A brief lives only during work and review. Once review approves, the branch's
last commit moves durable rationale into [decisions](../decisions.md) and open
gaps into [limitations](../limitations.md), and deletes the brief and its
task-board block, so the merge leaves nothing behind. Retired briefs are in
Git history; see [the history guide](../../history/README.md).
